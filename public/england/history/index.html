THE RULES

Everybody else gets a turn.

We remove all matches involving the excluded clubs that competed in each historical season. Three points per win. No made-up goals and no reallocated points.

If an excluded club wasn't in the Premier League, it can't be removed from that year's fixtures. Some seasons therefore contain more surviving teams.

Original CC0-licensed match results are preserved, so the list of excluded clubs can be changed and every season recalculated without changing a single score.
